# Kothe Viswanath - Portfolio

Personal portfolio website showcasing my work in ML infrastructure and platform engineering.

**Live Site:** [https://vishwa419.github.io](https://vishwa419.github.io)

## Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Animations:** Framer Motion
- **Diagrams:** Mermaid
- **Deployment:** GitHub Pages

## Features

- Interactive tag cloud for skills
- Animated timeline for experience
- Project showcase with architecture details
- Terminal-themed design
- Fully responsive

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/         # Page components (Home, Experience, Projects, Skills, Contact)
├── data/          # Static data for projects and experience
└── lib/           # Utilities and helpers
```
